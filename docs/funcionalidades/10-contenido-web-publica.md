# 10. Contenido, web pública y navegación

> Parte de `docs/Catálogo Demo Flexygo - Funcionalidades.md` (secciones 62-67, 72, 73, 76, 97-99).

## 62. Multiidioma

La aplicación debería permitir al menos:

- Español.
- Inglés.

Opcionalmente:

- Francés.
- Portugués.

---

## 63. Responsive

Debe funcionar correctamente en:

- Ordenador.
- Tablet.
- Smartphone.

---

## 64. Tema claro y oscuro

Podría incluir:

```text
☀ Tema claro
🌙 Tema oscuro
```

---

## 65. Personalización por cliente

Algunos clientes podrían disponer de:

- Logo personalizado.
- Color corporativo.
- Productos destacados.
- Catálogo específico.

Permitirá enseñar capacidades de personalización.

---

## 66. Configuración del catálogo

Desde administración se podrán configurar:

- Logo.
- Nombre.
- Colores.
- Banner.
- Imagen principal.
- Productos destacados.
- Promociones.
- Textos.
- Redes sociales.
- Datos de contacto.

---

## 67. Banners

El administrador podrá crear banners.

Ejemplo:

```text
Nueva colección 2027
Hasta -20 %
Ver colección
```

Configurables por:

- Fecha.
- Imagen.
- Texto.
- Enlace.
- Orden.
- Audiencia.

---
