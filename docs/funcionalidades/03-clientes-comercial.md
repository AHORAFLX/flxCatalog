# 03. Clientes y gestión comercial

> Parte de `docs/Catálogo Demo Flexygo - Funcionalidades.md` (secciones 17, 18, 19, 47, 51).

## 17. Clientes

El administrador podrá gestionar clientes.

Información:

- Código cliente.
- Razón social.
- Nombre comercial.
- CIF/NIF.
- Dirección fiscal.
- Direcciones de envío.
- País.
- Provincia.
- Población.
- Código postal.
- Teléfono.
- Email.
- Web.
- Persona de contacto.
- Comercial.
- Tarifa.
- Descuento.
- Forma de pago.
- Riesgo.
- Límite de crédito.
- Estado.
- Fecha de alta.
- Notas.
- Documentos.

---

## 18. Contactos del cliente

Un cliente podrá tener diferentes personas de contacto.

Por ejemplo:

- Compras.
- Administración.
- Dirección.

Cada contacto podrá disponer de acceso independiente al portal.

---

## 19. Direcciones de envío

Un cliente podrá tener múltiples direcciones.

Ejemplo:

```text
Oficina central
Delegación Valencia
Delegación Madrid
Tienda Barcelona
```

Al realizar el pedido podrá seleccionar dónde debe enviarse.

---

## 47. Perfil del cliente

El usuario podrá modificar:

- Nombre.
- Email.
- Teléfono.
- Contraseña.
- Idioma.
- Dirección.
- Preferencias.
- Notificaciones.

## 51. Gestión de clientes

El administrador podrá:

- Crear clientes.
- Modificar clientes.
- Bloquear clientes.
- Asignar tarifas.
- Asignar descuentos.
- Gestionar contactos.
- Gestionar direcciones.
- Consultar pedidos.
- Consultar facturas.
- Consultar incidencias.
- Consultar documentos.
- Consultar actividad.
