# 08. Dashboards e informes

> Parte de `docs/Catálogo Demo Flexygo - Funcionalidades.md` (secciones 3, 49, 50, 88, 89, 90).

## 3. Dashboard del cliente

La página principal debería mostrar información resumida.

Por ejemplo:

- Pedidos pendientes.
- Pedidos enviados.
- Pedidos entregados.
- Último pedido.
- Importe comprado este mes.
- Importe comprado este año.
- Productos comprados recientemente.
- Productos más comprados.
- Productos favoritos.
- Pedidos pendientes de pago.
- Ofertas pendientes.
- Notificaciones.
- Promociones disponibles.
- Documentos recientes.

También se pueden mostrar gráficos:

- Compras por mes.
- Compras por familia.
- Evolución del gasto.
- Productos más comprados.
- Estado de pedidos.

Esto permite mostrar las capacidades de **dashboards y gráficos de Flexygo**.
